# Kleiderschrank Kompakt

Deutschsprachige Web-App: ein privater digitaler Kleiderschrank mit Kaufarchiv.

Das Frontend ist eine React-Single-Page-App (Vite, TanStack Router, Tailwind CSS, shadcn/ui). Projektregeln und Architektur stehen in `CLAUDE.md`.

## Entwicklung

Voraussetzung: Node.js 20.12 oder neuer und npm.

```sh
npm ci
npm run dev
```

Weitere Befehle:

```sh
npm run build      # Produktions-Build nach dist/
npm run preview    # gebautes Frontend lokal ansehen
npm run typecheck
npm run lint
npm test
```
